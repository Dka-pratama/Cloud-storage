# Cloud Storage

</div>

Cloud Storage adalah aplikasi desktop berbasis Java yang dirancang sebagai antarmuka untuk berinteraksi dengan layanan Cloud Storage melalui API Oracle Cloud Infrastructure (OCI).

Aplikasi ini bertujuan mempermudah pengguna dalam mengakses dan mengelola penyimpanan cloud melalui antarmuka desktop, tanpa harus selalu berinteraksi langsung dengan API melalui terminal.

#### ✨ Fitur

Fitur yang tersedia akan disesuaikan dengan implementasi aplikasi saat ini.

- Antarmuka desktop berbasis Java.
- Tampilan modern menggunakan FlatLaf.
- Dukungan pengolahan data JSON menggunakan Gson.

#### 🛠️ Teknologi

| Teknologi | Keterangan                     |
| --------- | ------------------------------ |
| Java 21   | Bahasa pemrograman utama       |
| Maven     | Manajemen dependensi dan build |
| FlatLaf   | Tema antarmuka Java Swing      |
| Gson      | Pengolahan data JSON           |

#### 📋 Persyaratan

Sebelum menjalankan aplikasi, pastikan perangkat telah memiliki:

- JDK 21 atau versi yang kompatibel dengan konfigurasi proyek.
- Apache Maven, jika Maven Wrapper tidak tersedia.
- Git untuk mengambil source code.

#### 🚀 Instalasi

##### 1. Clone repository

```bash
git clone https://github.com/Dka-pratama/Cloud-storage.git
```

##### 2. Masuk ke direktori proyek

```bash
cd Cloud-storage
```

##### 3. Build aplikasi

```bash
mvn clean package
```

##### 4. Jalankan aplikasi

Perintah menjalankan aplikasi bergantung pada konfigurasi entry point dan plugin Maven di proyek ini. Pastikan kelas utama sudah ditentukan sebelum menambahkan instruksi eksekusi final.
